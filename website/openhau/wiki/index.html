OpenHaU 26.1 Preview user guide

OpenHaU is an offline billing workspace for small housing associations. The application interface supports Russian and Romanian; this guide describes controls in English. The current currency is MDL.

This is a preview, not certified accounting software. Use fictional records for evaluation and compare real calculations with an established system. Regulated reporting and turnover/balance statements are not available in 26.1.

Quick tour

  1. Install the desktop application and inspect its fictional demonstration project.
  2. Choose the interface language and theme in settings and inspect organisation details.
  3. Explore accounts, services and tariffs, then readings.
  4. The first demonstration account has charges of 1047.44 MDL for October 2026. The second intentionally lacks meter data.
  5. Select an account in the receipt workspace and inspect the preview.
  6. Save with the disk control or Ctrl+S / Cmd+S.

Before starting a real organisation, export the demonstration project if needed and use the empty-database action in settings. Do not treat the sample as an already configured production database.

Mac status

The DMG contains Intel and Apple Silicon binaries targeting macOS 12.6 or later. Launch and a superficial check were reported successful on Monterey after removing a Telegram quarantine attribute. Detailed persistence, printing and full workflow acceptance remain pending. The preview has no Apple Developer ID signature or notarization.

Support

Include the application version, OS, processor architecture, steps and exact error when reporting a problem. Remove resident names, addresses, balances and private identifiers before sharing screenshots or JSON.
