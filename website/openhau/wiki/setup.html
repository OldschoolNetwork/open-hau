Organisation and personal accounts

Organisation

Enter the current organisation name, association code, CF/IDNO, address, bank and IBAN in Settings → Organisation. Verify them in the receipt preview. The code is not repeated above the organisation name when both values match.

Accounts

Use Personal accounts to view, find and edit accounts. Account documents record opening, closing, changes to residents and changes to connected services. Keep the original account number when migrating historical records.

The account card includes its holder, property, residents, services, meters, additional objects and characteristics. Use dated documents for historical changes. Set the waste-charge person count for each month rather than replacing past months.

Services and tariffs

Each service has a calculation basis, unit, supplier, connected meter types and tariff history. Give each tariff an effective date. A transition-month price can be entered manually; the following month uses the next applicable tariff.

Table navigation

Click a column heading to sort ascending, then descending. A third click restores the original order. Shift-click adds a secondary sort column. Reset sorting clears the active sorting. Search and filters narrow the displayed records.
