Installation and updates

Windows

Download the current x64 installer from the official release and run it. Microsoft Edge WebView2 is required; the installer can obtain it when missing. The standalone EXE uses the same runtime but does not register file associations.

macOS

Open the Universal DMG, drag OpenHaU to Applications and launch the installed copy. Intel and Apple Silicon are included. The minimum system is macOS Monterey 12.6.

The Mac package has a local code signature, not an Apple Developer ID signature or notarization. If macOS requests approval, use the application-specific Open action or the approval in Security & Privacy. Do not disable Gatekeeper globally.

First launch

Use Create database for a new association or Add existing for an ODB file. The welcome screen also offers documentation and update settings. Choose a preferred database under At startup if it should open automatically.

Interface language, theme and date formats are in Settings. Receipt language is independent from interface language.

Updates

Open Settings → Updates, choose Check for updates and install an available version. The application checks the downloaded package signature and asks to save pending work before installation. Automatic checking at startup is optional. The welcome screen opens only update settings without opening a database.

Keep an independent database backup before installing a new release.
