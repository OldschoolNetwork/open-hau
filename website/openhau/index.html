Utility accounting
for housing associations.

Keep personal accounts, enter meter readings, record payments and prepare monthly bills. OpenHaU works offline and saves the association’s records in a database file you can move between computers.

The workspace

Menus, separate working windows and quick access to the tools used every month.

Monthly accounting

Accounts, services and their history stay connected throughout the billing cycle.

Accounts and residents

Open and close personal accounts, keep changes to residents and services, and set the number of people charged for waste collection each month.

Organisation and accounts

Meters and tariffs

Individual and shared meters, dated readings, tariff history and monthly exceptions when allocating differences between a shared meter and its consumers.

Meter readings and charges

Payments and reports

Batch payment entry, allocation by service debt, account and service balance reports, and payment reports. Preview documents before printing or exporting PDF, XLSX or CSV.

Payments and reports

Receipts

Select the month, choose a design and add the organisation’s logo. Set the payment deadline and choose which meter readings and optional columns appear on the bill.

Use the built-in designs or the receipt editor. Save appearance configurations, print the selected layout or save a PDF.

Receipt settings

Database files

Save, move and back up the association’s records without a cloud account.

ODB format

The editable JSON-based ODB file holds the organisation, accounts, history and settings. Save writes changes back to the selected file.

Files and backups

Optional protection

Protect a database with a password and configure automatic backup copies to a selected location.

Database protection

Local API

Inspect, query and edit databases from the command line. Writes validate the database, check its revision and retain a backup.
