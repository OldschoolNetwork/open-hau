# macOS preference artwork

These coloured category illustrations are adapted from the free V1 edition of
[3dicons](https://3dicons.co/), by Vijay Verma (CC0 1.0).

Source: https://github.com/realvjy/3dicons
Author asset host: https://pub-821312cfd07a4061bf7b99c1f23ed29b.r2.dev/v1/front/color/
License: https://3dicons.co/about

The transparent originals are cropped and resized to 96 × 96 pixels. They are
used for preference categories; command menus and compact toolbars retain
small monochrome symbols.
