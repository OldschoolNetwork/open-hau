# Receipts, logos and PDF

## Appearance

Select one or more accounts in the receipt workspace. Scroll its controls if the
printing actions are below the window edge.

Studio, Compact and Classic are available. They are layout variants, not decorative
background collections. Decorative themes and a custom template editor are future
work.

Choose Russian, Romanian or bilingual receipts, a colour and a 9–16 pt type size.
A dark interface does not turn the printed sheet dark.

## Organisation logo

The logo control accepts SVG, PNG, JPEG and WebP files up to 2 MB.
SVG is sanitized and embedded as an image. Complex effects or external references
may not survive; use a simple self-contained SVG or a raster alternative.

The logo is included in the full project JSON. Removing it from the receipt does
not delete its original file from the computer.

## Saved configurations

Enter a configuration name and save it, then select it from the configuration
list when needed. The preview supports up to 20 saved configurations; an existing
name replaces that entry. Save the whole project after changes.

## Printing and PDF

Use the print/PDF control:

- On Mac, use the system print dialog's PDF action.
- On Windows, select Save as PDF or an available PDF printer.
- Check A4, scale, margins, selected printer and page count before confirming.

If embedded printing is unavailable, export standalone HTML, open it in a browser
and print there. Browser dates, URLs and other headers/footers depend on print
settings and may be disabled when the dialog provides that option.

Print one sample first. Check bank details, totals, Romanian ă â î ș ț, page breaks
and monochrome legibility. Colour must not be the only way to distinguish meaning.
