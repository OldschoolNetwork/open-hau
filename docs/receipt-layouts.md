# Receipt layouts

- **Studio:** asymmetrical circular background, charge table beside a separate
  rounded balance panel, meter history below both columns.
- **Compact:** narrow edge stripe, condensed tables and a wide two-column balance
  block for economical printing.
- **Classic:** formal centred masthead, double rules, a framed balance panel and
  detachable payment notice.
- **Ribbon:** angled geometric bands, a ribbon-shaped masthead and a full-width
  total bar.
- **Botanical:** soft organic background shapes, rounded tables and alternating
  corner treatments, with the balance panel aligned left.
- **Heritage:** the familiar accounting-form structure with its notice, legible
  grid, organisation logo and improved logical divisions.
- **Aero:** a bank-statement appearance with pale blue glass-like gradients,
  curved panels, striped rows and a serif organisation heading.
- **Custom:** configurable font, border, alignment, background pattern and economy
  mode, stored as reusable appearance presets.

All layouts keep the same amounts and physical meter data. Decoration is separate
from the content and uses light shades; totals and table boundaries remain readable
when printer backgrounds are disabled. Check the system print preview for the
chosen paper, scaling and printer. These appearance presets are not a free-form
page-layout editor.
