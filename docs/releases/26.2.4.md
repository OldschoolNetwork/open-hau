# OpenHaU 26.2.4

- Table headers sort rows in ascending or descending order. Shift-click adds a secondary sort field; Reset sorting restores the original order. Sorting handles numbers, dates and account identifiers.
- Batch payment entry keeps its comment and action buttons below the scrolling table. Enter and Shift-Enter move between payment amounts. A search field, payment-method lookup icon and clearer toolbar backgrounds improve navigation.
- Local API queries support multiple sort fields before pagination without modifying database contents.
- The macOS build uses an ad-hoc code signature and verifies both Intel and Apple Silicon architectures. macOS may still require first-launch approval because this build is not notarized.

Includes the database label and update-entry corrections from 26.2.3. Database schema and financial records are unchanged.
