# OpenHaU 26.2.5

- macOS preferences use a compact category grid, a search field and Show All navigation, following the pre-Ventura layout.
- The macOS system menu bar provides application commands, standard text editing, workspace shortcuts and keyboard accelerators. The optional internal menu toolbar folds left and expands right.
- macOS menus and controls use rounded selections and system colours. Compact icons use SF Symbols available on the running Mac; preference categories use small CC0 illustrations.
- Mac keyboard labels distinguish Command, Control, Option and Shift. Windows keeps its existing Fluent interface.
- Imported group payments support unposting, editing and reposting in open periods. Original service allocations and the source document are retained; amount differences go to the selected maintenance service. Reposting does not duplicate payments. Closed periods and linked transactions remain protected.

Universal macOS packages include Intel and Apple Silicon support with a minimum of macOS Monterey 12.6. The app has a local signature and is not notarized by Apple; first-launch approval may be required.

Database format and financial records are unchanged. Signed update packages are provided for Windows and both Mac architectures.
