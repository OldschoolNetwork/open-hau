# OpenHaU 26.2.3

- Database cards display the current organization name from the database, including changes made through the local API. Reading a portable database label does not load its financial history. Locked or unavailable databases retain their saved labels.
- Updates are available directly from the database chooser, the workspace desktop and the Help menu. The chooser opens only the Updates settings pane without opening a database; the workspace opens Settings → Updates.

Includes the receipt header correction from 26.2.2. Database contents and schema are unchanged.
