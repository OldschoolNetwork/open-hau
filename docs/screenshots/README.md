# Screenshot provenance

These images show the actual 26.1 interface running in the local browser preview
with the built-in fictional demonstration project. The preview uses localStorage;
these are not evidence of native SQLite or macOS behaviour.

- overview-light.jpg: overview in the light theme.
- settings-dark.jpg: settings in the dark theme.
- receipt-studio.jpg: Studio receipt with Romanian output.

The application currently supports Russian and Romanian, so its localized text
remains visible. The project documentation is in English.
Captures exclude browser chrome, desktop overlays, cursor decorations, working
databases and personal information. No generated replacement UI is used.
