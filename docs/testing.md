# Проверка 26.1 Preview

Автоматические проверки: `npm test`, `npm run check`, `npm run build`,
`cargo check --manifest-path src-tauri/Cargo.toml`.

Демонстрационные данные включают два вымышленных счёта. У первого
начисление 1047.44 MDL: вода 309.90, электричество 566.04, мусор 17.50,
содержание 150.00, банковская услуга 4.00. У второго показания не заполнены:
это намеренно демонстрирует предупреждение о неполных данных.

Перед реальной эксплуатацией проверить:

- Сохранение, повторное открытие, резервные копии и восстановление через
  импорт данных; при ошибке чтения сохранение не должно затереть базу.
- Все темы и переключение системной темы при открытом приложении.
- RU/RO, длинные названия, несколько квартир, нулевые показания и переплаты.
- Закрытие месяца, следующий период и повторное открытие для исправления.
- Печать и PDF всех трёх шаблонов на целевых Windows и Monterey 12.6.
- SVG и растровые логотипы, читаемость на чёрно-белом принтере.
- Архитектуры Intel / Apple Silicon, первый запуск и упаковку DMG.

Автотесты не подтверждают соответствие молдавской отчётности и не заменяют
сверку с бухгалтером.
